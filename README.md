🥌 "WinCurl" version 3.0


📋 Overview:
  

"WinCurl" is a high-performance, Python-based curling simulation built with Pygame. Experience the thrill of the ice with realistic physics, networking capabilities, and a retro-inspired aesthetic.
🚀 Features:

    Physics Engine: Precision curling stone mechanics.

    Multiplayer: Built-in IRC-based network matchmaking for competitive play

    Visuals: Clean, responsive UI with procedural graphics & sounds.

    Cross-Platform: Developed on Linux.

🛠 Technology:

    Language: Python 3

    Graphics: Pygame

    Build System: Buildozer / Android SDK

📦 Getting Started:

    Clone the repository or use pip: pip3 install wincurl3

    Install dependencies:

    pip install pygame

    Run the game:

    python main.py

📱 Android Build:

This project is configured for automated Android deployment via GitHub Actions, when they work.

    Android rumble support is still being optimized, grab the latest APK from the repo.
